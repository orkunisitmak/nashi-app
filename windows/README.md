# Nashi for Windows

Mac and Windows 0.7.5 are published with the shared 45-format / 27-tool catalog and aligned Home, Library, paste, preview and window-management workflows. See [the feature parity and verification matrix](FEATURE-PARITY.md) for implementation, evidence and platform differences.

Nashi uses WPF / .NET 10, the same pear artwork, file garden, rounded cards, gold actions and light/dark palette as macOS, with Windows keyboard, drag-and-drop and system tray conventions. Build with `dotnet publish windows/Nashi.Windows -c Release -o build/windows/Nashi`. The output is self-contained; users do not install .NET separately. Keep the portable folder together in a writable location so updates can replace it safely.

On a normal launch, Nashi appears as a compact island at the top center of the screen. In this compact state, use **+** to choose files, the clipboard button to paste, and **▶** to open actions for the selected files. Click the island to open its redesigned dashboard, or drop files onto it; press Escape or the chevron to collapse it. The dashboard keeps edit, convert, and download actions close by, with the full workspace available for Library and advanced options. Opening files from Explorer opens the expanded dashboard directly.

The expanded dashboard also has local Notes, To-do, Timer, File tray, Media, Calendar, and Mirror widgets. Media can follow a selected Windows media session; its artwork appears when available, the compact island offers play/pause, and its mini-player has skip and seek controls. Notes support bold, italic, and underline while preserving older plain notes. To-dos can be starred, archived when complete, and restored. Island menus and selectors follow the active theme. Calendar events can be read from a local `.ics` export or synced from an HTTPS/webcal subscription link; meeting links open from the event row, and an event starting within 30 minutes appears in the compact island. Bluetooth connection changes appear briefly in the compact island. Mirror shows a live camera preview only after you start it, and stops the camera when you leave its tab or close Nashi. The compact island also reports live timer and battery state when those are available. Notes, open tasks, calendar path, subscription URL, and tray references are saved in `%LOCALAPPDATA%\Nashi\island-widgets.json`; tray items can be dragged into other apps and remain file references rather than copied content.

The shared catalog contains 27 tools and 46 input formats. It includes photo editing, framing/collages, crop/annotation/redaction, QR/PDF tools, document/Pages/EPUB/spreadsheet/slides conversion, archives/subtitles, media tools and public web downloads. Runtime setup is available from Home. Download URLs and SHA-256 hashes are pinned in `Toolchain.cs`, `OfficeRuntime.cs` and `MetadataService.cs`; upstream licenses remain separate from Nashi's MIT license. See [third-party notices](THIRD-PARTY-NOTICES.txt).

The local Pocket widget saves copied text only when you click **Save copied text**; it stores up to 12 snippets and can copy them back to the clipboard. Nashi does not monitor the clipboard in the background.

Library and preferences live in `%LOCALAPPDATA%/Nashi`, outside the portable application folder. Library keeps the last 50 successful exports and clipboard imports. Text imports use UTF-8 and image imports use lossless PNG. Signed public update staging verifies the manifest, archive hash, version and trusted signature before restart.

While dragging in Explorer or another application, **Ctrl** opens tools, **Shift** conversion and **Alt** file actions. Settings can change the three chords. **Ctrl+Shift+D** opens a copied public media link. The app can remain in the system tray.

**Ctrl+O** chooses files; **Ctrl+V** imports files/text/images/links outside text fields; **Ctrl+1/2** switches Home/Library; **Ctrl+F** searches; **Ctrl+U** checks updates. **Ctrl+Space** opens the selected files' wheel; choose **Convert** to select an output format. Arrows/Tab choose an item, Enter opens it and Escape closes it. In the Home file list, **Delete** removes the selected entries from Nashi without deleting the original files.

Media editors use **Space** for play/pause, **Left/Right** for one-second seeking, **Shift+Left/Right** for frame steps, **I/O** for range marks and **Shift+Space** to play the selected range. Crop supports drag, Shift ratio lock, selection move/resize, aspect presets and Enter save. Annotation supports Select/Move, Delete and Ctrl+Z. Normal text-field editing is preserved.

`Nashi.Verify` checks the shared engine and security foundation. `Nashi --smoke-test` runs real Windows keyboard, clipboard, OLE drag, Library, editor and export checks and writes diagnostic JSON/PNG artifacts. See [verification details](FEATURE-PARITY.md#commands-and-evidence) before interpreting a CI artifact as a completed test or official release.
