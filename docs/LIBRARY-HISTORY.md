# Library history controls

On macOS and Windows, use a history row's context menu to remove that entry.
Library's Clear history action asks before removing all entries. These commands
remove saved history references; they do not delete files, clipboard imports or
exported folders. Appearance and other preferences are kept.

Changes persist across restarts and clear a removed row's selection. The controls
are unavailable during an active operation. A later successful operation creates
a new history entry normally. Windows reports a failed save and retains its
in-memory entries if the data folder cannot be written.
