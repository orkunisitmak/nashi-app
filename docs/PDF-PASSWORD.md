# Password-protected PDFs in Organize PDF (macOS)

When Organize PDF opens a locked document, enter its password and choose Unlock
PDF (or press Return). An incorrect password leaves the entry controls available
for another attempt. Editing and export remain disabled until the document opens.

The password is held only in the open editor session and passed to the existing
PDF engine for export. Reset and closing the editor clear the entry. It is not
saved in Library history or preferences. The original document remains unchanged.
Existing restrictions on editing rich encrypted PDFs still apply. Other PDF
operations and multi-file password prompts are outside this first UI scope.
